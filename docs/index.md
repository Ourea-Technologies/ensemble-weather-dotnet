# EnsembleWeather for .NET

The official .NET SDK for the [Ourea](https://oureawx.com) probabilistic weather API: ensemble forecasts for the
contiguous United States where every value is a distribution, with probabilities and storm totals computed by
the server from the full ensemble.

```sh
dotnet add package EnsembleWeather
```

- [Getting started](articles/getting-started.md): the 60-second quickstart, keys and tiers.
- [Probabilities](articles/probabilities.md): `ProbabilityTerm`, window totals and quantile ranges.
- [Errors, retries and caching](articles/errors-and-retries.md).
- [API reference](api/EnsembleWeather.yml).

The product guides live at [docs.oureawx.com](https://docs.oureawx.com).
